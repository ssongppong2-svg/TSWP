# 개발일지 (Godot 판)

## v0.6.1 — 다듬기
- **화면 흐름**: 타이틀(로고·캠프 배경·메뉴) → 게임 → Esc 일시정지(계속·설정·조작법·캠프로·타이틀로·종료) → 전멸/승리 결과 화면(처치·쓰러짐·금화·시간)
- **설정**: 전체/음악/효과음/환경음 음량, 화질(낮음~최고), 전체 화면, 화면 흔들림, 번쩍임 줄이기, 피해 숫자 — `user://settings.cfg` 에 저장
- **HUD 새로 그림**: 9칸 도트 판, 직업 초상 아이콘, 패시브 보석, 숫자가 들어간 체력바(위급하면 깜빡), 스킬 칸(쿨타임이 위에서 걷히고 남은 초 · Q 키캡 · 준비되면 금테 번쩍), 하트로 남은 부활, 금화(늘면 톡 튐)
- **상황 힌트**: 늘 떠 있던 조작 설명 줄을 없애고, 처음 할 때만 키캡+설명이 잠깐 뜬다 (이동·공격·측면 점프·직업 표지·위급·보스)
- **화면 노이즈 제거**: 갓 레이·가장자리 어둡게·원경 하늘/능선의 바둑판 디더를 계단 띠로 바꿈 → 캐릭터·나무 위 점무늬 사라짐
- **가림 처리**: 주인공을 가리는 나무는 디더 대신 깔끔한 원 구멍(1px 어두운 테), 캐릭터는 그늘에서 덜 어두워져 실루엣이 읽힘
- **진흙 데칼**: 구멍처럼 보이던 짙은 타원 → 길 색에 가까운 젖은 흙 + 발자국
- **피해 숫자**: 연속으로 맞으면 엇갈려 쌓임, 큰 피해(40↑)는 큰 글씨
- **출구 표지**: 지역 끝에 가까이 가면 "▲ 다음 지역" 이 떠오름
- **전환**: 마름모 도트 전환 (페이드 대신)
- **카메라**: 북쪽 끝에서 캐릭터가 HUD 밑에 깔리지 않게 위쪽을 더 열어 둠
- **버그**: 날아가는 화살·주사의 주인이 먼저 사라지면 나던 오류(지운 노드 접근) 수정 — `Hit.sanitize()`
- **기록**: 지역을 옮겨도 처치·쓰러짐 기록이 이어지도록 파티 번호(slot) 기준으로 모음. 새 판에 금화·기록 초기화

## 시험
- `godot --headless --path . -- --selftest` : 타이틀→시작→일시정지→설정→계속→전멸→결과→캠프→타이틀 흐름 자동 확인
- `-- --map=forest --bot=cycle --quit=60` : 자동 플레이로 오류 찾기
- `-- --title --autostart=3 --map=forest --bot=cycle --demo` : 타이틀부터 시작하는 시연 (영상용)
