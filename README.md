# TSWP — The Strongest Warrior Party (Godot 판)

8인 온라인 협동·트롤 로그라이크. **탑다운 3/4 시점 ↔ 높낮이 구간에서 카메라가 돌아가며 횡스크롤로 전환**되는 3D 도트 하이브리드.

- 엔진: Godot 4.7.2 (Forward+), 3D 세계 + 도트 텍스처·빌보드 스프라이트, 480×270 저해상도 렌더 → 정수 배율 확대
- 이 브랜치(`godot`)는 Godot 판 원본 보관용. `main` 브랜치는 Unity 설계 원본.
- `tools/` : 도트 그림·효과음·음악을 만드는 파이썬 생성기 (numpy · scipy · Pillow)

자세한 진행은 `docs/개발일지.md`.
